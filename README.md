# سامانه یکپارچه مدرسه مشاهیر آینده — فاز اول (دبیرستان)

بک‌اند: Laravel 12 + PostgreSQL + Redis (`backend/`) — فرانت: Vite + React 19 + TS + Tailwind 4 (`frontend/`).
کنترل دسترسی فقط سمت سرور، مبتنی بر یک فایل واحد ماتریس مجوزها؛ پیش‌فرض ممنوع؛ خارج از محدوده = ۴۰۴.

## اجرای محلی

```bash
# ۱) بک‌اند
cd backend
php artisan migrate:fresh --seed --force   # PostgreSQL روی پورت 5433
php artisan serve --port=8000              # + redis-server روشن باشد

# ۲) فرانت
cd frontend
npm install
npm run dev                                # http://localhost:3000 (پروکسی /api → 8000)
```

## ماژول‌های پیاده‌شده

- **هویت و دسترسی**: ورود OTP، تعویض نقش/مدرسه، نقش سفارشی هر مدرسه (CRUD)، ماتریس مجوزهای ۶۱تایی با ۱۶ قید شرطی
- **حضور و غیاب**: پیش‌نویس → نهایی‌سازی → اصلاح (ش۹/ش۷) + پیامک غیبت به ولی‌های دارای پرچم (ش۱۴) با وضعیت و تلاش مجدد
- **تکالیف**: تعریف، ارسال با تشخیص دیرکرد، نمره‌دهی، مشاهده ولی فقط‌خواندنی
- **آزمون آنلاین**: طراحی تستی/تشریحی، ذخیره خودکار نسخه‌ای، تایمر سرور، تصحیح خودکار/دستی، ش۶ visibility
- **نمره و کارنامه**: چرخه تأیید/انتشار، نسخه‌بندی کارنامه، تغییر با دلیل (append-only)، PDF
- **اعلان‌ها**: کانال رسمی با هدف‌گیری، مرکز اعلان با تب‌ها، تنظیمات کانال (ش۱۴)
- **خانواده**: پیوند ولی با پرچم‌های مستقل، حکم دادگاه (غلبه بر پرچم‌ها)، لیست تحویل‌گیری (ش۱۳ پیشنهادی)، رضایتنامه با سیاست یک/دو‌ولی
- **کلاس آنلاین**: اسکای‌روم — `SKYROOM_DRIVER=fake` برای دمو، `skyroom` با `SKYROOM_URL` برای سرویس واقعی
- **سایر**: برنامه هفتگی، ورود CSV با خطای سطری، تنظیمات مدرسه، لاگ append-only

## قوانین غیرقابل‌مذاکره

پیش‌فرض ممنوع؛ کنترل فقط سمت سرور؛ `school_id` روی همه مدل‌ها (خارج از محدوده = ۴۰۴)؛ ماتریس مجوزها یک فایل واحد که Seeder و تست‌ها می‌خوانند؛ UTC/timestamptz (شمسی فقط نمایش)؛ ورود فقط OTP؛ موبایل/کد ملی رمزنگاری‌شده؛ ulid برای شناسه‌های بیرونی.
